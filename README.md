# E-Commerce Store - ReactJS Assignment Project

A responsive, production-ready e-commerce web application developed with **ReactJS**, **Bootstrap 5**, and public **REST API** integration.

---

## 🎯 Project Objective
Develop a responsive e-commerce web application using ReactJS with live API integration. Users can browse products, search/filter items, view detailed specifications, and manage an interactive shopping cart with local persistence.

## 📋 Requirements Checklist

| Requirement | Implementation Detail | Status |
| :--- | :--- | :---: |
| **Fetch products from a public REST API** | Fetches 20 dynamic products and 4 categories from the specified endpoint with error handling and fallback cache | ✅ Completed |

## 💻 Getting Started Locally

1. **Clone the repository:**
   \`\`\`bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd <REPO_NAME>
   \`\`\`

2. **Install dependencies:**
   \`\`\`bash

3. **Start the development server:**
   \`\`\`bash
